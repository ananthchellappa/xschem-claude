# xschem
A schematic editor for VLSI/Asic/Analog custom designs, netlist backends for VHDL, Spice and Verilog. The tool is focused on hierarchy and parametric designs, to maximize circuit reuse. Work of Stefan Schippers.

My work : using Claude Code to enhance. This is *the* branch to be using. To use it, after building (assuming not "installed") : `/path/to/src/xschem --script /path/to/src/cadence_style_rc --logdir /where/you/want/logfile` If no `--logdir`, you end up with an `Xschem.log` in the current directory (from where you launch).

Please send me your feature requests. Or open up a new discussion on a feature. Issues also ok.
