# xschem
A schematic editor for VLSI/Asic/Analog custom designs, netlist backends for VHDL, Spice and Verilog. The tool is focused on hierarchy and parametric designs, to maximize circuit reuse. Work of Stefan Schippers.

My work : using Claude Code to enhance. Please use the "fluid-editing" branch - it has all the features. Property forms is WIP.

Please send me your feature requests. Or open up a new discussion on a feature. Issues also ok.

Very early-stage intro video : https://www.youtube.com/watch?v=gtipAPsql_M

Latest additions (label drag, Alt-Shift-Q for Edit with Apply to All Selected, Check-and-Save, DC sweep a variable, etc) : https://xschem.blogspot.com/2026/11/since-waveform-viewer-in-xschem-free.html
