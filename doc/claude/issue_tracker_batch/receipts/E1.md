## 4. "These should never have been filed" — the process lesson

The clearest single example:

> **`1377_isolate_opt_in`** — *"test_sim_registry_isolate is OPT-IN, one line a suite author has to remember… Options: (a) keep opt-in and add the sweep to a periodic audit; (b) make test_scratch clear by default with an explicit `test_scratch -keep-registry` opt-OUT; (c) leave it and accept re-discovery."*

This is a **test fixture's default setting**. It has no surface, no wording, and no consequence any XSCHEM user could observe. It is the literal subject of *"I don't get into the weeds of the test-suites"* — and it sat on their queue as a decision they owed.

Four more of the same kind:

- **`1385`** — two test rows pass or fail on the **window width a previous run left behind**; options are "pin a geometry, widen the search, or drive a pair at a fixed zoom."
- **`1431`** — *"a co-simulation golden has been one nanosecond stale… re-baseline row GE24, or treat the shift as a regression to chase."*
- **`1440`** — *"test_ase_optier_0963's display arm stalls after row N3 every time"*: force the race, skip the row, or accept a 260 s timeout.
- **`1314`** — asks the user to choose **which batch item does the work first** and whether to re-scope a crew's permitted file list. That is project scheduling.

**The pattern worth naming.** Eleven of the twenty-four (`1375`, `1377_isolate_opt_in`, `1377_repo_root_litter`, `1385`, `1397`, `1399`, `1400`, `1431`, `1440`, `1458`, `DD-8`) are **test-harness or tracker mechanics**. Five more are **internal data-model or API-contract choices** that were correctly decided and then filed anyway — several explicitly saying *"Forced by…"* in their own text. **An entry that states its own decision was forced is not a question.** A filter as cheap as *"does this have a surface?"* would have caught every one.

**Two MINE entries carry real damage the user should still be told about — as information, not as a question.** `1397` permanently displaced 50 of their 101 saved window geometries (its own text: "NOT RECOVERABLE"), and `1458` is the same hole still open. The *fix* is ours; the *fact* is theirs to know.
