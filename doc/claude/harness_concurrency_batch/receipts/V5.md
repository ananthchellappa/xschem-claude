## Corrections and additions — the next crew reads this

1. **⚠ `pgrep -af 'run_regression'` SELF-MATCHES AND READS AS A COLLISION.** This batch's own
   solo-ness idiom returned **four** hits when only one run existed: the real `timeout` and
   `tclsh` processes, plus **two Bash tool wrapper shells whose command *text* contains the
   pattern** — my own T1 launcher and the pgrep command itself. In a batch whose subject is
   detecting concurrent runs, the detector has a false-positive mode that would make a solo run
   look contended, and could be used to excuse a red. **Check the pid in `/proc`, or match the
   process's `args` against an anchored `^[0-9]+ (timeout [0-9]+ )?tclsh run_regression`
   pattern**, rather than `pgrep -af` on a bare substring. This is the same defect class as
   `W12b`: matching a shared namespace by pattern instead of by identity.
2. **A bounded waiter does not survive the turn that owns it.** I armed a correctly-bounded
   background waiter with a named expiry outcome, and it was orphaned when the turn ended,
   while T1 itself kept running — so the completion had nobody to report to. The batch's
   recorded lesson is *"a stall must be a named outcome"*; the corollary is that **a completion
   must be too, and someone must be awake to name it.** Wait in the **foreground** with a
   bounded deadline, or re-check state explicitly on resuming. The cost here was one idle turn;
   the recorded cost of the same shape elsewhere is 8 h 7 min.
3. **The trailer beats `Start`/`Finish` on a NODISPLAY box** — `incr t1_cases` at `:842`
   precedes the `continue` at `:856`, so `cases` stays 84 where `Finish` drops to 73. Worth
   adding wherever 1481 is described, because the brief's framing implies the reverse.
4. **`171` is this run's measurement, not a constant.** Confirmed moving with the failure count
   by an earlier crew. Report what you measure.
5. **Running `test_ase_core` from the repo root does NOT test C11's ambient-litter tolerance** —
   its watch list collapses to one directory. The meaningful test is under T1, whose cwd is
   `tests/`. A future crew "confirming C11" standalone is confirming the weaker half.
6. **`results.log` is green again**, byte-identical to `results.2484691.log`. V4 left the
   canonical name holding a red (the optier flake); that is now superseded.
