## The defect, confirmed in source before changing anything

V4 measured the failure; the brief asked me to confirm the characterisation by reading the
code. **CONFIRMED, verbatim, as it stood in HEAD:**

```tcl
265: set em_before [llength [glob -nocomplain -directory /tmp -type d xschem_emergencysave_*]]
266: lassign [run_child $f_w12 3000 40] rc el out
271: set em_after [llength [glob -nocomplain -directory /tmp -type d xschem_emergencysave_*]]
275: check W12b-no-emergency-save-corpse \
276:   [expr {$em_after == $em_before}] \
277:   "-- $em_before -> $em_after in /tmp; an external SIGTERM on this same hang adds one"
```

Three independent things make it false-red:

1. **The glob is over all of `/tmp`** — a namespace shared with every process on the box.
2. **`src/main.c:42` puts no pid in the name.** Read, not assumed:
   `my_snprintf(emergency_prefix, ..., "xschem_emergencysave_%s_", get_cell(...))` — cell name
   plus `create_tmpdir`'s random suffix. Every corpse on this box is called
   `xschem_emergencysave_untitled_<10 random letters>`. **Nothing in the name identifies the
   producer**, which is why no glob-and-filter could have rescued the count.
3. **`llength` is a count.** Two corpses appearing and one being removed scores clean; one
   foreign corpse appearing scores dirty.

### Why a set difference alone is *not* the fix — a correction to the brief

The brief said to make it a set difference following C11. **A set difference is necessary but
cannot be the assertion**, and I would have shipped a row that still reds under concurrency if
I had stopped there: names that appear during the window are still names from a *shared*
namespace, so a foreign corpse is "new" too. C11's set difference works because
`untitled~.sch` in the repo root has a **bounded, local** producer set; `/tmp` does not.

The ground truth is that **the child names its own corpse**. `src/main.c:45-52`:

```c
if( !(emergency_dir = create_tmpdir(emergency_prefix)) ) { ... }
rename(xctx->undo_dirname, emergency_dir);
fprintf(errfp, "EMERGENCY SAVE DIR: %s\n", emergency_dir);
```

and `run_child` merges stderr (`2>@1`, `:104-105`), so the marker is already in `$out`.
**I proved this directly rather than reasoning about it** — probe under a real SIGTERM:

```
rc=124
PROBE-ALIVE
rename dir (null) to /tmp/xschem_emergencysave_untitled_cdfcbaafbf failed
EMERGENCY SAVE DIR: /tmp/xschem_emergencysave_untitled_cdfcbaafbf
FATAL: signal 15
--- /tmp count: 45 -> 46 ---
```

So: **the delta is kept and REPORTED; the assertion is on identity.** The foreign traffic that
used to red the row is now printed as evidence.

   bounded and local. In a shared namespace (`/tmp`), identity is the only sound test — and it

   coordinates for one sentence; **all four were honest**, and the divergence was a live crew's
