## ⚠ The correction that matters most: 0805's prescribed fix was wrong, and measurably so

0805 says to anchor the arm "with the same optional-trailer tolerance the other two readers
use". That is right for `OVERALL: ok` and **wrong for `RESULT: ALL PASS`**.
`tests/headless/test_ase_bus_bits_0159.tcl:294` emits:

```tcl
puts "RESULT: ALL PASS ($npass checks[expr {$skipped ? ", $skipped group(s) skipped" : {}}])"
```

— so whenever a group is skipped it prints `RESULT: ALL PASS (12 checks, 2 group(s) skipped)`,
whose trailer contains an **inner parenthesis**. `\([^)]*\)` stops at that inner `)`, fails the
end anchor, and scores a green shipped suite **FAIL**. That is a *live* regression, not the
latent divergence 0805 is about, and it would have been introduced by the fix as written.

So the two alternatives deliberately differ, and both files now say why:

* `OVERALL: ok` → `\([^)]*\)`, byte-identical to `run_suites.sh:161` and verdict-identical to
  `banner_complete`. **K20 asserts all three agree**, so it cannot drift.
* `RESULT: ALL PASS` → `\(.*\)`. The other two readers **do not implement this spelling at
  all**, so there is nothing for it to diverge from, and C45/C46/C47 hold it alone.

The sweep that made the tightening safe was taken from the emitter statements themselves, not
from prose or from the issue's 2026-08-25 claim:

```sh
grep -rhoE '(puts|echo)[^"]*"(RESULT: ALL PASS|OVERALL: ok)[^"]*"' tests/ --include='*.tcl' --include='*.sh' | sort -u
```

Every shipped emitter is bare or carries exactly **one** parenthesised trailer. No suite emits
trailing words, so 0805 was still latent when it was closed — re-confirmed, not inherited.
