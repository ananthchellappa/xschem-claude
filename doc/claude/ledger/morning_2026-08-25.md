## The finding of the night

The notify-cluster crew's fix **reproduced, inside itself, the exact defect it was
written to end.**

0675's thesis is that the channel measures PROC IDENTITY when the question is SINK
REACHABILITY — a channel can pass its own liveness test and reach nobody. The fix
introduced `notify_reach`, whose ciw and statusbar arms honestly probed the widget
they write. Its **popup arm did not**:

```
!$tk -> dead(no-Tk)   ;   else -> visible
```

It never looked at `.xschem_notify`. So with `style popup` and the popup merely
iconified:

```
exists=1 mapped=0 state=iconic | popup=visible | notify_returned=1 | witness_sinks names it
```

Alive by its own new test, reaching nobody, in silence. Sharper still: with
`.xschem_notify.t` destroyed, `notify_popup` returns **0** — the writer failed — in
the same call where the arm reports `visible`.

The crew's own adversary caught it, the lead's brief had demanded exactly that red
state, and the crew reverted rather than shipped. **That is the process working
twice in one night.** The 1885-line diff is preserved for the next attempt.

It also proved the popup half is a **HEAD-level defect**, not an artifact of the
attempt — same probe on pristine HEAD gives `exists=1 mapped=0 state=iconic`,
`witness_sinks={ciw log popup}`. Filed as **0800**.
