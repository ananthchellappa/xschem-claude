## 0689 + 0690 + 0698 — the harness stops lying

`237fc966`. **No product code touched** — `git diff 0cd74b4b HEAD -- src/` is empty.

**T1's three standing FAIL lines were the harness, not the tree.** The crew
reported 3 -> 0, and the lead's own full `tclsh run_regression.tcl` **confirms
it independently**, measured against the four things that can each hide a failure:

```
rc                                              = 0
grep -cE '(FAIL$|GOLD\?$|RESULT\?$|^FATAL)'     = 0     counted failure patterns
grep -cE "couldn't execute .xschem.|exit 127"   = 0     binary never launched
grep -c 'Total num fail: 0'                     = 32    every case, not a sample
```

The last line is the one that matters most: 32 of 32 cases individually report
zero failures, so the clean top-line is not a sentinel that stopped looking.

### The bug was one anchor

```tcl
-  set sentinel [regexp -line {^OVERALL: ok$} $body]
```

`$` is end-of-line, so `OVERALL: ok (30 checks)` — what a suite that reports a
count actually prints — never matched, and the case was scored as *"did not
complete cleanly ... crashed, aborted mid-script, or a check failed"*. Three
suites had been red for that reason, and every report for days carried
"T1 3 FAIL, pre-existing" while nobody looked.

The fix is a shared `banner_rule.tcl` exposing `banner_complete`, `banner_died`
and `regression_case_failed`, so the relaxation cannot silently swallow a real
death. The sabotage matrix proves the second half was necessary rather than
decorative: stubbing `banner_died` to `return 0` reddens **K9, K10, K12, K19
only**, while K1-K8 and K13 stay green — i.e. a fix that merely stopped the false
reds would have been a **strictly worse harness** than the one it replaced, and
would have gone unnoticed for exactly the reason 0689 did.

### The disease behind the symptom

Four issues filed, and two of them name the real problem: **there are three
separate readers of the same completion banner, with three different rules.**

* **0802** — `full_audit.sh` scores a pass banner *followed by a death marker* as PASS.
* **0805** — `full_audit.sh`'s pass arm is only PREFIX-anchored, so it accepts a
  banner with trailing junk that the other two readers reject.
* 0803 — `execute` pops a modal dialog on a failed launch, hanging any suite under X.
* 0804 — `test_ase_core` NT14 asserts headless-only behaviour in both arms.

0689 was one instance of a class: **the banner rule is written down in three
places and agrees in none of them.** `banner_rule.tcl` is the beginning of the
cure, not the whole of it — the other two readers still have their own copies.
