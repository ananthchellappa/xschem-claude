## 4. One regression, caused and fixed inside the item

The new suite went 36/36 green on the first draft **and T1 went from 0 to 4**:

```
FAIL: A11-2 the whole sentence reaches the CIW while the status line is fitted,
and every status-line write goes through the budget -> {... 1 1 1 0} (exp {... 1 1 1 1})
HARNESS: headless/test_op_annot did not complete cleanly (exit=1)
```

Row A11-2 of `test_op_annot.tcl` — a file A1 does not own — enforces a
**structural** property of `utils/annot_mode.tcl`: every non-comment line writing
`xschem statusmsg -hold` must name `_annot_fit` **on the same line**, so a
sentence added later cannot bypass the 255-byte budget. The first draft split
that call over two lines with a backslash continuation: behaviourally identical,
structurally forbidden. Fixed by hoisting the sentence into `set m` and writing
the call on one line, with a comment recording that it is a contract, not layout.

Worth stating plainly: **the item's own 36-check suite could not see this.** The
tier list is what caught it.
