## ⛔ THE ONE DEPARTURE FROM THE BRIEF, AND IT WAS FORCED BY MEASUREMENT

```tcl

**That line does not fix the defect.** `.rdw*` matches the descendant
`.rdw.p.t` exactly as readily as the toplevel `.rdw`, so the deliberate pane

independently on both display arms**, and it was then re-run as a sabotage

```

The discriminator that works is the one the window manager itself supplies: the
map-time grant lands on the **TOPLEVEL** (`[focus]` eq `.rdw`, detail
`NotifyAncestor`), every deliberate landing lands on a **CHILD** (`.rdw.p.t`).
Row **K16** now keeps `string match` out of that proc permanently.

Issue 1306's *"or equivalently"* formulation is refuted by the same
measurement: the WM's grant has `[focus]` **inside** `.rdw`, so that test
rejects the one event the hand-back exists to catch.
