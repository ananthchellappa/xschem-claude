## 4. Decisions, each with its ladder rung and its rejected alternative

1. **A third argument, not `TEXT_CTX_INSTANCE_ANNOTATED`** (L2, reinforced by I1).
   Rejected the plan's own proposal: `annot_class_mask()` and `annot_text_layer()`
   both open with `ctx != TEXT_CTX_INSTANCE`, so a fourth value silently kills the
   implicit node-voltage class and 0615's colour override on exactly the annotated
   instances the feature targets; and a ctx *value* cannot carry a per-instance
   datum, so six sites would each compute the gate. Cost stated: two entry points
   on one core is a wrapper, not a second builder.
2. **The D-6 gate is `get_annot_overlay()`'s own chain, factored** (L1 / I1).
   Rejected (a) calling `get_annot_overlay()` — `++annot_overlay_count` reds row
   O13; (b) requiring a non-blank **value** — a second parser of the block's
   format, and it would let a sheet paint an OP block over parameters it declined
   to hide. **Consequence recorded, not discovered:** a registered device over a
   dead raw is decluttered while showing label-only rows. `rule` debt
   `1244_A3_blank_valued_block` — **the status-E question**.
3. **`select.c:709` is one of the six, and one line of `scheduler.c` comes with
   it** (L2). Rejected leaving `symbol_bbox()` on the two-argument entry: the pick
   would answer over blank canvas. Residual filed as **1252**.
4. **`draw.c:1143` (drag ghost) and `:10310` (hover outline) follow the declutter**
   (L2). Rejected exempting the hover box: it would outline text that is not on
   screen. A fully decluttered FET makes `inst_text_bbox()` return 0 and the hover
   falls back to the symbol shape.
5. **1249 fixed the issue's way — export `annot_name_token()`** (L1 / I1, and the
   brief's rule that a recommendation stands unless a measurement refutes it).
   Rejected `!(flags & TEXT_ANNOT_NAME)`: cheaper and resting on the same builder,
   but it trusts a cached classification inside three render loops where a
   stateless predicate cannot be wrong.
6. **1246 fixed at both sites, with the two out-of-item suite rows in the same
   commit** (L2). Rejected a bare `| 3` without `& ~4`: 1246's own text says
   clearing bit 2 is deliberate (issue 0868, D5-1's shape).
7. **1247: the shipped rule is NOT the planned one, and the substitution is
   recorded** (L3 — **status E**). The plan chose "stamp only on the 0 → nonzero
   arming edge"; traced against the red suite it cannot separate the three states
   the rows pin and reds row A26. Shipped:
   `if(old && (old ^ mask) == ANNOT_SHOW_NOPARAM) return;`. Rejected: "do not stamp
   when the mask is unchanged" (**refuted by measurement** — the pair is 3 → 11 → 3
   and both writes change the mask), and routing the `xschemrc` arm through the
   setter (reverses D2 of 0688).
8. **`annot_declutter_exempt()` is `(flags & TEXT_ANNOT_NAME)` alone** (L2, forced
   by a row this item does not own). The planned three-arm version calls
   `annot_class_mask()` and reds row **U35** of `test_op_annot.tcl` ("defined once
   and called once"); the folded `flags & (VOLTAGE|CURRENT)` spelling is verbatim
   what the same row forbids (0678's landmine). Both arms are provably dead at the
   rung's position. Cost stated: the function's soundness now lives 60 lines away,
   in the arm order that row **A20** pins.
9. **No `xschem text_hidden` reflection verb** (L2) — A2's open question answered
   **no**, in writing. A3 has three behavioural windows A2 lacked (SVG, PS,
   `instance_bbox`/`instance_at`), so rows A19–A22 corroborate rather than carry.
10. **`cadence::_annot_msg`'s `& 7` blindness is not closed here** (L2). A3 owns
    neither `utils/annot_mode.tcl` (item A4's) nor row V21. Filed as **1251** with
    the consequence stated and a repair that keeps V21 green, rather than leaving
    the plan and the code disagreeing.

**The three misses, each chased to a cause:**

* **A17 under `SB-GATE-ALWAYS` — a real coverage hole.** A17 compares mask 1 and
  mask 9 at `hide_symbols=2` and asserts they are identical; with the gate ignoring
  `hide_symbols` they are *still* identical, because the keep-name filter has
  already reduced both to names only. Filed as **1254**.
* **A11 under `SB-EXEMPT-GONE` — a wrong prediction, not a hole.** The shipped
  `annot_declutter_exempt()` carries only the NAME arm (decision 8), so
  annotation-classed texts are exempt by **placement**; neutralizing the helper
  cannot reach them. Their mechanism is covered by `SB-ORDER-BELOW-SHT`/A20.
* **A9 under `SB-OVERLAY-EATS-ITSELF` — a hole in the variant.** Repointing the
  probe at `text_hidden_inst` is behaviourally inert (`HIDE_TEXT_OP` is 64 → the
  probe returns above the rung; and `n = -1` stops it again). Supplementary `SB5b`
  killed the overlay for real and A9 went red at `{0 8 0 0}`, so A9 is not vacuous.
* **`SB7b` — a second real coverage hole.** Removing *only* the new
  `scheduler.c` sync line leaves all 610 checks green: row A15 loads the sheet
  immediately before annotating, which leaves the cache cold. Filed as **1254**.
